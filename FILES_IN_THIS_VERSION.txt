THREE CHANGES TO THE GOAL SLIDER

1. Releasing now updates the row.
   The goal was being saved correctly, but the row kept showing the old value.
   refreshValues binds from a cached copy of the label list, so it was
   re-drawing the stale goal; only a rebuild re-reads the file. Tapping showed
   the new value because the popup reads the file directly. It now always
   rebuilds, which also re-sorts if the order depends on goals.

2. The column adjusts what it was already showing.
   Sliding no longer swaps the column for a raw goal figure. In Rem it counts
   down as the goal grows; in Goal it shows the goal. Clock and sum modes
   don't change for the row being adjusted — their value comes from the rows
   above it — so those fall back to showing the goal, or there'd be no
   feedback at all.

3. New ladder: 5, 10, 15, then 15 more per step.
   From a 60-minute goal, dragging up gives 65, 70, 75, 90, 105, 120.
