FIXES THE v38 DELETE BUG

Deleting a run didn't remove its time. Two causes:

  1. The log stored whole minutes. A 17-second run was written as 0 minutes,
     so deleting it subtracted nothing. The log now carries exact milliseconds
     in a new column, duration_ms.

  2. Standalone adjustments (a -5m with no run attached) were hidden from the
     Notes screen entirely. They're now listed, marked "adjustment -5m", and
     can be deleted like anything else. They show even with "Show runs with no
     note" off, since they never have a note.

A third problem turned up while fixing it: saving a note rebuilt the row from
its first six fields, which would have dropped the new column every time.
Fixed too.

YOUR CURRENT -4:43
Open that label's Notes screen. You should now see both the run and the
adjustment listed. Delete both and the total returns to zero.

Runs logged before v39 have no exact figure recorded, so deleting one subtracts
its rounded minutes — the precision was never written down and can't be
recovered.
