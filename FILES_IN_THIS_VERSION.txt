Focus v70 — complete file list.

Task completions are now recorded in two places.

  1. completed_at on the task. The editor shows "✓ 9 Sep 3:15p" beside how long
     it took.

  2. A row in timer_log.csv, typed "task_done", carrying the task text, the
     time accrued against it, and its estimate.

Both, because they answer different questions. The field tells you when you
finished something while the task still exists. The log row survives the task
being edited, archived or deleted — and it's what a date range can count, which
a task's own lifetime figure never could.

Not written into notes: notes are free text tied to a run, so completions would
be mixed in with what you actually wrote, and it would only catch the ones that
happened to coincide with a timer switch.

A new "type" column on the log. Rows without it read as "run", which is what
they all were, and existing files have their header upgraded in place.

IMPORTANT, and handled: the time on a completion row is ALREADY inside its
label's runs. Every reader excludes these rows or it would count twice — the
Notes screen, the range totals, the per-label export, and note attachment,
which now finds the last RUN rather than simply the last row.

This also unlocks task totals on the range screen, which had to be left out of
v69 because task time had no timestamps.
