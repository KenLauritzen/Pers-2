FIXING TODAY'S FIGURE (long-press the right-hand column of a row)

  Match log…   Shows today's figure next to what the log has for today, then
               sets today to the log's figure. Writes NOTHING to the log.
               This is the fix for Brain Exer: today 17:49, log 0:00, so it
               becomes 0:00 plus the run going now.

  Set today…   Type what today should read (1:30, or 90) and the difference
               is recorded as an adjustment. One step instead of tapping.

  Time row     Plus is now green and minus red, like Goal, so +1h and −1h
               can't be mixed up. The word "Time" stays blue.

Deleting an entry in Notes and Match log now use the same rule for what counts
as today, so they always agree.
