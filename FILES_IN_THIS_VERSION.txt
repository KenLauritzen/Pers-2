Focus v64 — complete file list.

  1. The totals row no longer clips.

     includeFontPadding="false" on a wrap_content height removes the space a
     font reserves for descenders — so the tail of the "p" in "@8:30p" was cut
     and the digits looked shaved. The three totals now take the full 48dp row
     height and keep their font padding.

  2. Tasks show on two lines, in the editor and on the row.

     ▸ 30m / 300m  10%
       RDM-1608 - Ryan uploaded not licensed detail

     The description gets the full width and WRAPS, so a task can be several
     lines and the running row grows with its content. The 0-5 show count is
     the dial — 2 or 3 is probably the practical setting now.

     Figures show even at zero, so the shape doesn't change once a task is
     started.

     The row block is still one TextView; spans make the figure lines smaller
     and dimmer than the description.
