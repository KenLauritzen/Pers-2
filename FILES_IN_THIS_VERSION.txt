TASKS (idea 27)

Tap the pencil under the running row to open the task editor for that label.

  Statuses cycle when you tap a task's marker:
      open  ->  doing (▸)  ->  done (✓, greyed)  ->  archived (×, hidden)

  Four rather than a tick box, because "finished" and "get it off my screen"
  are different moments.

  Tasks accrue their own time, but ONLY while their label's timer is running
  and the task is marked "doing". The LABEL TOTAL STAYS AUTHORITATIVE — task
  time will usually sum to less, and that gap is honest: thinking time,
  interruptions and forgetting to advance a task all live in it.

  Only one task can be "doing" at a time across all labels. Two accruing
  against one timer would double-count.

  "Show on the row" is 0-5 per label. Zero opts that label out entirely.

  Each task can carry an estimate in minutes. The editor shows estimate /
  actual side by side.

  The running row grows to fit its tasks; every other row keeps its height.

The file is tasks.csv, beside the log, and it is CSV on purpose — it is shaped
so a spreadsheet of tasks-by-category can be merged into it later. One row per
task, label as plain text, estimate in whole minutes. It is included in the
Settings export.
