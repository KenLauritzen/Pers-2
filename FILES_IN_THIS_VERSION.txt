TWO CHANGES

1. Delete a logged run (idea 35)
   In a label's Notes screen, tap an entry and use Delete, or long-press it.
   The confirmation names the entry — date, time, duration, note — and says
   what will happen to today's total.

   A run from today also comes off today's counters, so the main screen and
   the log stay in agreement. An older run only loses its line, since that
   day's counters rolled over long ago.

2. Rem shows how far past the goal (idea 36)
   Was "0:00" once a goal was passed. Now shows "-0:15" in bright peach, which
   stays legible against the burnt-red overage bar.

   Start and ETA needed no change: ETA counts from now, so an overrun has
   already pushed it later. Start is a fixed plan by design.
