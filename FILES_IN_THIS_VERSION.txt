Focus v50 — complete file list.

  1. Export from the Notes screen.
     A button beside Done writes a CSV of that label's rows only, through the
     same share sheet and file-location dialog as the Settings export.

     The screen's filter applies: with "Show runs with no note" off, only runs
     with notes are included, so the file matches what you were looking at.
     The dialog tells you which you got.

     Written as Focus_<label>.csv beside the main log, overwritten each time.

  2. Adjustments now obey the "Show runs with no note" filter.
     v39 made them always visible so a stray adjustment could be found. In use
     that meant rows with no note kept appearing with the filter on. They now
     hide like anything else without a note — turn the filter on to find one.
