Focus v84 — complete file list.

Adds "Fill all days from a layout…" to the week menu, in both the dated week
and the default week.

  Pick a saved layout and it goes into all seven columns at once, in the
  manual order it was saved with.

  Labels with NO GOAL arrive as parked blocks — greyed, at the foot of each
  column, costing nothing. So every label is present and ready to be dragged
  up on the days it applies to, rather than being added one at a time on the
  days that need it.

  It asks before replacing if the week already has blocks.
