The progress bar is considerably more visible.

  progress  #2A4A2E -> #3A6841
  overage   #4A2A18 -> #8C4726

Measured against the track each sits on, the old colours scored 1.47 and 1.14
contrast — and 1.0 means indistinguishable. The overage red was effectively
invisible, so going past a goal barely changed the row. Both now sit above 2.1.

The limit is text legibility, since everything on the row sits on top of the
bar. These values keep the 32sp timer above the 3:1 large text needs and the
label above 5:1. There's room to go brighter if it still reads as subtle — the
timer's contrast is what gives first.

Also: the "goal exactly met" figure was #C97064, which scored 1.85 on the
brighter bar. It now uses the same peach as the overage, which reads at 3.5+.
The text already tells them apart — "0:00" versus "-0:15".
