The T pill is a dropdown with four options instead of a cycle.

    T0     nothing on any row
    T1     one outstanding task on every row
    T2     two
    Dflt   each label's own count, the 0-5 set in its popup

Dflt is the interesting one. The per-label counts had been governing only the
running row, so every other label's count sat idle unless that label happened
to be running. Under Dflt they all take effect at once — a label set to five
shows five, one set to none shows none — and the running row stops being a
special case.

That gives three different views:
    planning   T1 or T2, uniform and comparable
    working    Dflt, each label as detailed as you decided it deserves
    clean      T0

Under T0, T1 and T2 the running row still uses its own count, as before.

Row heights will vary more under Dflt, since labels differ. Worth a few days
to see whether that reads as useful or untidy.
