Eight changes to how tasks read.

  Hints                 #5C736E -> #8FA39E, all eight of them. That's 2.87
                        contrast up to 5.50 — the old value was under
                        two-thirds of what normal text needs, which is why it
                        disappeared in daylight.

  Done in the editor    #CBD9D5, struck through — matching the row, which was
                        fixed in v68 while the editor kept the old colour.

  Completion date       The redundant ✓ before it is gone. The marker beside
                        it already shows one. Date and time unchanged.

  Missing estimate      Shows "min?" instead of an empty line. That empty line
                        was what pushed the description below the marker and
                        made the text look misaligned.

  ✓ and ✕               Both mint. Archived is the same colour at 55% alpha —
                        one colour saying "finished", the fade saying "put
                        away".

  × became ✕            The multiplication sign is an ASCII-height glyph and
                        looked half the size of the tick beside it.

  ▸ on the main row     Its own 1.5× span. It sits inside a line shrunk to 0.8
                        for the figures, making it the smallest glyph on the
                        row — and it's the only thing showing which task is
                        accruing time.

  Figures line          Follows the marker: amber accruing, mint finished,
                        neutral waiting.

Note: done tasks don't appear on the main row at all since v74, so the mint
there is for one consistent rule rather than for visible effect.
