Focus v65 — complete file list.

Fixes a dead end: setting a label's task count to zero hid the task block and
the edit icon with it, leaving no way back to the editor or the count.

The label popup — long-press any row's right column — now has a Tasks row
beside Goal and Time:

    Tasks   −   [3]   +     Edit...

The count is adjustable there, and Edit... opens the editor whatever the count
is. Neither depends on the block that disappears at zero.

The editor's own count control has been removed. Two controls for one setting
is how they drift apart, and there'd be no telling which you last used.
